# Skywalker Suite

**Skywalker Suite** is a complete IT company website solution built with **Laravel** and modern front-end technologies. It provides a fully functional corporate website for IT businesses, including services, projects, contact forms, and dynamic content management.

---

## Features

- Fully responsive and mobile-friendly design.
- Multi-slide carousel on the homepage for featured services and solutions.
- Dynamic **About**, **Services**, **Portfolio**, and **Contact** pages.
- Interactive contact form integrated with backend email functionality.
- Vendor/partner carousel to showcase business collaborations.
- Sticky top navigation bar with active route highlighting using Laravel standard rules.
- Modular architecture with Blade templates for easy maintenance.
- Optimized for performance and SEO.
- Uses Bootstrap 5 for styling and responsiveness.
- Optional admin panel to manage services, projects, and content.

---

## Technologies Used

- **Backend:** Laravel 10  
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5, Blade Templates  
- **Database:** MySQL / PostgreSQL (configurable)  
- **Version Control:** Git & GitHub  
- **Libraries & Plugins:** Owl Carousel, WOW.js, FontAwesome
